Wall Calendar privacy policy

Last updated October 18, 2026.

What it accesses

Wall Calendar uses the Google Calendar API to read the signed-in user's calendars and events, and to create or delete events when the user asks it to on the display. It does not access any other Google data, such as email, contacts or files.

Where data goes

Calendar data travels only between Google's servers and the home display it runs on. Nothing is sent to any other server, sold, shared, or used for advertising. The app's sign-in token is stored only on that display, in the app's private storage.

Removing access

Access can be removed at any time at myaccount.google.com/permissions, or by choosing Sign out in the app's Settings.

Google API Services User Data Policy

Wall Calendar's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
